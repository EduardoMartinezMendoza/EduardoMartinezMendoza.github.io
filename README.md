# Eduardo Martínez Mendoza — Academic Website

A lightweight, responsive personal academic website. The public page includes a short biography, two publications, and an institutional email address. It deliberately omits the full CV, phone number, references, and other personal details.

## Preview locally

Open `index.html` in any web browser. No additional programs or build step are needed.

## Publish with GitHub Pages

1. Sign in to GitHub and create a **public** repository named `YOUR-GITHUB-USERNAME.github.io` (replace the placeholder with the actual username). For a project page, any repository name also works, but the public URL will include the repository name.
2. Upload **the contents of this folder**, not the folder itself, to the root of the repository. The top-level files must include `index.html`, `styles.css`, `favicon.svg`, and `.nojekyll`.
3. Commit to the `main` branch.
4. In the repository, go to **Settings → Pages → Build and deployment** and select **Deploy from a branch**, with branch **main** and folder **/(root)**. Save.
5. Your personal site will be available at `https://YOUR-GITHUB-USERNAME.github.io/` after GitHub finishes deploying.

GitHub documentation: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Edit content

- Edit `index.html` for the biography, publications, and email address.
- Edit `styles.css` for fonts, colors, spacing, and layout.
- Edit `favicon.svg` for the browser-tab monogram.

The site has no analytics, external scripts, third-party fonts, or tracking pixels. All links and assets are relative (apart from the arXiv papers and the email link), so it works as both a user homepage and a project website.

## Notes

- The website has not been published automatically; publishing requires access to the intended GitHub account.
- There is no full-CV PDF linked on the homepage, by design. It can be added later if desired.
- Verify any future changes to dates, submission statuses, and affiliations before publishing updates.
